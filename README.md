# تطبيق شطر (Shatr) - برنامج تحميل الفيديوهات والصوتيات

## كيفية الرفع على GitHub:
1. ارفع ملف `index.html` إلى مستودعك على GitHub.
2. انزل إلى الإعدادات **Settings** > **Pages**.
3. اختر الفرع `main` ثم اضغط **Save**.
4. سيعطيك GitHub رابط موقعك المباشر لاستخدامه في AppYet أو متصفحك!
